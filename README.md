# 🚌 Bus-Reservation-System

A desktop-based Bus Reservation System developed using Java Swing for the graphical user interface (GUI) and C++ for backend operations. This project demonstrates Object-Oriented Programming (OOP) concepts and fundamental programming principles.

✨ Features

- 🎟️ Bus ticket booking
- 🪑 Seat allocation and availability
- 🚌 Bus routes management
- 👥 Passenger information management
- 💾 File handling for saving and loading bookings
- ⭐ VIP passenger functionality
- 🖥️ Interactive Java Swing GUI

🛠️ Technologies Used

- Java Swing — GUI Development
- C++ — Backend Implementation
- OOP — Inheritance, Polymorphism, Encapsulation, and Operator Overloading
- File Handling — Persistent booking records

⚙️ Setup & Execution

1. Compile the C++ source code using a compatible compiler.
2. Update the C++ executable path in the Java code.
3. Place "bus-background.jfif" in the appropriate directory.
4. Run the Java application to launch the GUI.

📚 Concepts Demonstrated

- Classes and Objects
- Inheritance and Multiple Inheritance
- Runtime Polymorphism
- Operator Overloading
- Friend Functions and Classes
- Constructors and Copy Constructors
- Input Validation and File Handling
